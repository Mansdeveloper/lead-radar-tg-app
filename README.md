# ⚡ Lead Radar Telegram Bot (Micro-SaaS)

Бот для мгновенного перехвата заказов с бирж фриланса (Хабр Фриланс, FL.ru) с монетизацией через **Telegram Stars** и виральной реферальной системой.

---

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Настройка переменных окружения
Создайте файл `.env` на основе `.env.example`:
```ini
BOT_TOKEN=ВАШ_ТОКЕН_ОТ_BOTFATHER
STARS_PRICE=250
FREE_MAX_DAILY_LEADS=3
FREE_DELAY_SECONDS=900
PARSE_INTERVAL_SECONDS=60
REFERRAL_PREMIUM_DAYS=7
```

### 3. Проверка работоспособности пайплайна
Запустите проверочный скрипт:
```bash
python test_pipeline.py
```

### 4. Запуск бота
```bash
python main.py
```

---

## 💡 Архитектура и Механики Монетизации

1. **Freemium-Delayer (Конверсионная ловушка):**
   - Free: Заказы приходят с задержкой **15 минут** (до 3 в день). За 15 минут горячий заказ уже разбирают.
   - Premium: Заказы приходят **мгновенно (0 секунд)** + безлимит + фильтры.
2. **Оплата в 1 клик через Telegram Stars:**
   - Не требует регистрации ИП, юрлиц и модерации банка.
   - Пользователь оплачивает встроенными звездами Telegram прямо в диалоге.
3. **Виральный рост без бюджета:**
   - Пригласи друга по реферальной ссылке (`/profile`) $\rightarrow$ получи **+7 дней Premium бесплатно**.
   - Самоподдерживающийся цикл в чатах фрилансеров.
